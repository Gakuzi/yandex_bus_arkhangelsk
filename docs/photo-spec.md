# Спецификация: «Фото места» в шапке карточки транспорта

> 🟢 **Статус: частично реализовано (2026-10-09).** Встроенные фото-заглушки мест
> готовы (локальный набор пейзажей + маппинг по названию остановки). Координатная
> часть (парсинг координат остановки с Яндекс.Карт и живой подбор фото с Wikimedia)
> остаётся планом и в коде отсутствует.

## Цель
Чтобы карточка остановки ассоциировалась с конкретным местом/районом города:
в шапке показывается фотография знаменательного места, района или города.
Фото подбирается автоматически по названию остановки, а пользователь может
переопределить его вручную.

### Модуль-маппинг `photos.js`
Подключается как ресурс типа `module`:
`/local/yandex_bus_arkhangelsk/photos/photos.js`

Функции:
- `ybMatchDistrict(name)` — возвращает `{id, file, label, full}` по названию остановки
  или `null`.
- `ybPlacePhotoUrl(name, districtOverride)` — URL фото по приоритету:
  1. `district_override` (ручной оверрайд района);
  2. автоопределение по названию остановки;
  3. фолбэк — город (`city.jpg`).
- `ybAllPlaces()` — список всех мест (для настроек).

### Интеграция в карточку
- `yandex-bus-card`: в шапке показывается фото места + подпись района.
- Модалка деталей маршрута использует то же фото места и кнопку
  «Открыть на Яндекс.Картах».
- Настройки редактора: `photo_mode` (`auto`/`custom`), `photo`, `photo_label`,
  `district_override`. Если модуль `photos.js` не подключён как ресурс, карточка
  пытается загрузить его динамически.

## Плановая (не реализованная) часть

- **Парсинг координат остановки** с Яндекс.Карт (сейчас парсится только центр линии
  маршрута, координат остановки в коде нет). Целево: атрибуты `lat` / `lon` /
  `district` у сенсора.
- **Живой подбор фото по координатам** через Wikimedia Commons API
  (`geosearch` по `lat|lon`) с фолбэком на локальный набор.
- **`stop_photo_url`** с бэкенда как готовый результат, когда фронт-резолвер выключен
  (`photo_mode == 'backend'`, резервируется).

## Критерии готовности
- [x] Карточка показывает фото района/места из локального набора.
- [x] В режиме `custom` показывает своё фото.
- [x] При отсутствии района — фото города / градиент.
- [x] Все настройки редактируются в конфиге карточки.
- [ ] Сенсор отдаёт `district`, `lat`, `lon` (не реализовано — план).
- [ ] Wikimedia API интегрирован (не реализовано — план).
