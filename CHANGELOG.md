# Changelog

Все существенные изменения проекта — в хронологическом порядке (сверху вниз — новейшие).
Формат версий — [SemVer](https://semver.org/). Тег `vX.Y.Z` в HACS создаётся через
`scripts/release.sh <версия>`.

## [1.5.0] - 2026-10-09

### Added
- Карточка `yandex-bus-card`: фото-шапка с местом остановки — приглушённый пейзаж
  района/города подставляется автоматически по названию остановки.
- Встроенный набор фото-заглушек мест Архангельска: `www/yandex_bus_arkhangelsk/photos/`
  (15 пейзажей + фолбэк города) и модуль-маппинг `photos.js` (ключевые слова → район).
- Настройки фото в редакторе карточки: `photo_mode` (`auto`/`custom`), `photo`,
  `photo_label`, `district_override`.
- Модальное окно деталей маршрута получило фото-шапку места и кнопку
  «Открыть на Яндекс.Картах».

## [1.4.3] - 2026-10-09

### Fixed
- Убрано обращение карточки к несуществующим атрибутам (`stops_left`/`stops_count`) —
  число остановок теперь честная оценка по времени прибытия.
- Удалён мёртвый код (переменная `busUrl`, осиротевшие атрибуты `center_lon/lat/radius`).
- Обновлён README (описание модальных окон, явно указано, что карты в модалке нет).
- Добавлен `AGENTS.md` (карта проекта и конвенция разработки).

## [1.4.2] - 2026-10

### Fixed
- Убрана карта из модалки маршрута; в модалке теперь показываются остановки маршрута
  и число остановок до прибытия.

## [1.4.1] - 2026-10

### Fixed
- Модальные окна маршрута переведены на встроенный `ha-dialog` (затемнение,
  центрирование, закрытие по Esc).

## [1.4.0] - 2026-10

### Added
- Попап со списком остановок маршрута и картой автобуса (модальные окна в карточке).

## [1.3.0] - 2026-10

### Changed
- Современный `config_flow` (добавление/настройка остановки): подсказки, валидация
  ввода, понятные сообщения об ошибках.

### Chore
- Добавлен `.gitignore`.

## [1.2.0] - 2026-10

### Added
- Устойчивость парсера Яндекс.Карт: ретраи при сетевых сбоях, кэш последних успешных
  данных, защита от пустых/мусорных ответов.

## [1.1.0] - 2026-10

### Added
- Frontend-карточка v2 (`www/yandex-bus-card.js`): элементы `yandex-bus-card`,
  `yandex-bus-pylon-card` и визуальный редактор — единая замена разрозненных v1-карточек.
- Скрипт установщика на Raspberry Pi (`install.sh`) и скрипт релизов
  (`scripts/release.sh`, тег `vX.Y.Z` для HACS).

## [1.0.x] - 2026

- Первые стабильные версии интеграции IoT-класса `cloud_polling`:
  парсинг расписания остановки, выбор маршрутов, сенсоры прибытия.
- HACS/Hassfest валидация: лицензия, `issue_tracker`, бренд-ассеты, сортировка ключей
  манифеста, GitHub workflow для HACS/Hassfest.
