# AGENTS.md — карта проекта «Интеграция Транспорт Архангельск»

> Прочитай первым. Это «оглавление», а не справочник.

## 1. Что это за проект

Home Assistant-интеграция **`yandex_bus_arkhangelsk`** — отслеживание общественного
транспорта Архангельска. Парсит страницы Яндекс.Карт остановок и отдаёт в HA время
прибытия по маршрутам. В комплекте идёт frontend-карточка Lovelace
(`www/yandex-bus-card.js`) с табло остановки и модальным окном маршрута.

Репозиторий: `Gakuzi/yandex_bus_arkhangelsk` (публичный, HACS).

## 2. Критичное знание

- **Домен не менять** — `yandex_bus_arkhangelsk` (сущности и дашборды привязаны).
- **HACS обновляет только `custom_components/`**. Frontend-карточка в `www/` после
  релиза ставится отдельно: `scp` на Малинку в `~/homeassistant/www/yandex-bus-card.js`
  + рестарт HA. При bump версии обновляй ресурсы дашбордов (`?v=n.n.n`) — иначе браузер
  держит старые версии в кэше (Cache-Control max-age=31 день).
- **Яндекс блокирует iframe-карты** — интерактивную карту в модалке встроить нельзя.
  Показываем маршрут текстом (первая/конечная остановки, время, оценка числа остановок).
- **Яндекс не отдаёт** в открытых данных: реальное число остановок до автобуса и его
  live-позицию — они спрятаны в непубличном Xiva-протоколе. Поэтому число остановок —
  оценка по времени прибытия.
- Версия пакета живёт в `VERSION` и `manifest.json["version"]`. Релиз — через
  `scripts/release.sh` (v-tag → HACS видит обновление).

## 3. Приоритеты

1. Стабильность (не ломать установленное на Малинке)
2. Корректность данных и согласованность frontend ↔ backend
3. Структура HACS и валидный manifest
4. Простота установки/обновления
5. Актуальность документации при изменении поведения

## 4. Структура файлов

| Путь | Назначение |
|---|---|
| `custom_components/yandex_bus_arkhangelsk/` | Интеграция (backend) |
| `.../coordinator.py` | Парсер Яндекс.Карт + coordinator |
| `.../sensor.py` | Сенсоры остановки и маршрутов |
| `.../config_flow.py` | Настройка остановки в UI |
| `.../translations/{ru,en}.json` | Локализация |
| `www/yandex-bus-card.js` | Frontend-карточки + модальное окно маршрута |
| `hacs.json`, `manifest.json`, `VERSION` | Метаданные и версия |
| `install.sh`, `scripts/remote_install.sh` | Установка на Raspberry Pi |
| `scripts/release.sh` | Выпуск релиза (v-tag) |
| `.github/workflows/{hacs,hassfest}.yml` | Валидация HACS |

## 5. Проверка перед сдачей

```bash
node --check www/yandex-bus-card.js
python3 -m py_compile custom_components/yandex_bus_arkhangelsk/*.py
# версии согласованы: VERSION == manifest.json["version"] == тег релиза
# frontend не обращается к несуществующим атрибутам сенсора
# при изменении UI — обновлён README + CHANGELOG
```

## 6. Архитектурные решения (вкратце)

- Модальные окна — через встроенный `ha-dialog` (затемнение, центрирование, Esc).
- Число остановок до автобуса — оценка `minsLeft / 2.5`, не реальное значение.
- Карта в модалке не встраивается (блокировка Яндексом).
- Бэкапы HA на Малинке: 3 копии локально + Google Drive (см. память проекта).
